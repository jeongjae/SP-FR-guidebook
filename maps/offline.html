오프라인 준비

가이드북과 실제 길찾기를 출발 전 Wi-Fi에서 준비한다. 저장 완료 표시는 비행기 모드 점검까지 끝났다는 뜻이 아니다.

iPhone에 가이드북 저장

GitHub Pages 주소를 Safari에서 연 뒤 공유 → 홈 화면에 추가를 선택하고, 가능하면 웹 앱으로 열기를 켠다. 홈 화면에서 가이드북을 다시 연 다음 아래 버튼으로 전체 콘텐츠를 저장한다.

  1. Safari에서 이 페이지를 연다.
  2. 공유 메뉴에서 홈 화면에 추가를 선택한다.
  3. 홈 화면의 유럽 가이드북 아이콘으로 다시 연다.
  4. Wi-Fi에서 전체 저장을 마친 뒤 비행기 모드로 다시 열어본다.

Organic Maps 준비

로밍이 끊겨도 도보·운전 안내가 되게 하는 별도 지도 준비다. 출발 전 Wi-Fi에서 한 번만 해두면 된다.

오프라인입니다. KML 파일은 이미 이 기기에 있어 지금도 내려받을 수 있습니다.

실기기 검증 전이다. 아래 KML 8개는 빌드가 매번 XML 파서로 열어보고 핀 68개의 이름이 UTF-8 로 온전한지 확인한 파일이다. 한글·프랑스어 이름이 섞여 있다. 다만 Organic Maps 가 기기에서 이 이름들을 어떻게 표시하는지는 확인하지 않았다. 출발 전에 한 지역만 먼저 임포트해 핀 이름이 깨지지 않는지 직접 보고, 깨지면 나머지는 이 앱의 실행지도로 대신한다.

준비 순서

  1. Organic Maps 설치 — 무료·오픈소스·광고 없음. 계정이 필요 없다.
  2. 지도 내려받기 (Wi-Fi 에서) — 앱에서 프랑스와 스페인 지도를 받는다. 용량이 크므로 반드시 출발 전 Wi-Fi 에서 한다.
  3. KML 내려받기 — 아래 표의 파일을 이 기기에 저장한다.
  4. 임포트 — 저장한 파일을 열어 Organic Maps 로 열기 를 고른다. 핀이 앱의 북마크로 들어간다.
  5. 확인 — 앱의 북마크 목록에서 핀 68개가 보이고 이름이 깨지지 않았는지 본다.

숙소 핀 상태

[확정 숙소] 1개, [숙소 후보] 7개다. 확정 숙소는 예약 주소를 지도에서 재확인한 핀이다. 후보 핀은 목적지로 잡고 이동하면 안 된다. 현재 상태는 숙소 후보·확정 과 예약 현황 에서 확인한다. 예약이 잠길 때마다 KML 을 다시 만들어 이 페이지에 올린다.
