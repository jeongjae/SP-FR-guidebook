# 87. Visual Rights and Licensing Register v1.0

## 사용등급

| 등급 | 사용 가능 범위 |
|---|---|
| A | Jason·Julia 직접촬영 또는 직접 제작 도식 — 전권 사용 가능 |
| B | Public Domain / CC0 — 출처기록 후 사용 |
| C | CC BY / CC BY-SA — 저작자·라이선스·원문 링크 표기 |
| D | 관광청·기관 제공 — 해당 사용조건 확인 후 사용 |
| X | 상업 스톡, SNS, 블로그, 검색결과 이미지 — 별도 허가 없이는 사용 금지 |

## 자산별 필수 메타데이터

- Asset ID
- 원본 파일명
- 촬영자 또는 저작자
- 출처 URL
- 라이선스
- 다운로드/촬영일
- 수정 여부
- 크레딧 문구
- 사용 페이지
- 원본 보관 위치

## 현재 원칙

외부사진은 아직 패키지에 포함하지 않는다.  
여행 전에는 자체 도식과 실행지도를 사용하고, 여행 중 직접촬영한 사진을 우선 반영한다.
