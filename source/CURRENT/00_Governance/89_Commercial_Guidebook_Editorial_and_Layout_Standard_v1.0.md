# 89. Commercial Guidebook Editorial and Layout Standard v1.0

## 1. 목적

원고를 여행 운영매뉴얼에서 상용 여행가이드북으로 전환한다. 장소 나열보다 다음 질문에 답한다.

1. 왜 가는가?
2. 언제 가는가?
3. 무엇을 먼저 보고 무엇을 삭제하는가?
4. Jason·Julia의 여행스타일에 왜 맞는가?
5. 비·지연·피로가 생기면 무엇으로 바꾸는가?

## 3. 추천표시

| 표시 | 뜻 |
|---|---|
| 필수 | 해당 장의 정체성을 결정하는 일정 |
| 우선 추천 | 시간과 체력이 허용되면 기본안에 유지 |
| 선택 | 날씨·예약·취향에 따라 실행 |
| 대체 | 기본일정이 불가능할 때 교체 |
| 제외 | 과밀 또는 동선상 비효율 |

별점은 외부 평판이나 품질순위가 아니라 **이 여행계획에서의 편집 추천도**다.

## 4. 장소 설명 공식

`장소의 정체성 → Jason·Julia에게 의미 있는 이유 → 가장 좋은 시간 → 체류시간 → 앞뒤 동선 → 삭제조건`

## 5. 식당 카드 기준

실제 식당을 확정할 때 다음 필드를 사용한다.

- 역할: 시장점심 / 특별저녁 / 차량일 간단식
- 가격대: € / €€ / €€€
- 대표메뉴
- 분위기
- 예약난이도
- 추천시간
- 숙소·다음 일정과의 거리
- 휴무·재확인일
- 대체 후보

## 6. 시각적 읽기 원칙

- 긴 목록보다 3–5개 카드로 묶는다.
- 하루 일정은 Morning → Lunch → Afternoon → Evening으로 읽히게 한다.
- 핵심예약과 삭제순서는 굵게 표시한다.
- 표는 모바일에서 4열을 넘기지 않는 요약표와 상세표로 분리한다.
- 지도·사진·도식은 장식이 아니라 의사결정에 필요한 위치에 둔다.
