# TP 유럽여행 가이드북 편집 스타일 가이드 v1.0

## 1. 적용 범위
지역 챕터 8개, Reader Edition 8개, 통합 Master에 공통 적용한다. 사실관계나 일정의 의미를 바꾸지 않고 표기·구조·등급·시간 형식을 통일한다.

## 2. 표기 표준
- 여행 규모: **43일 일정·42박**
- 날짜: 본문 `9월 9일(수)`, 일정표 `9/9(수)` 허용
- 시간: 24시간제 `09:30`; 범위는 `09:30–11:00`
- 이동: `출발지 → 경유지 → 도착지`
- 지명: 첫 등장 시 `한글명(원어명)`, 이후 문맥상 한 형식으로 유지
- 교통: `렌터카`, `TGV`, `TER`, `Google Maps`
- 숙박 절차: `체크인`, `체크아웃`

## 3. 추천 등급
1. **필수**: 일정 정체성을 이루는 핵심
2. **우선 추천**: 시간과 체력이 허용되면 실행
3. **선택**: 취향·날씨·예약 상황에 따라 추가
4. **대체**: 악천후·지연·휴관 시 교체
5. **제외**: 이번 여행에서는 실행하지 않음

## 4. 일자별 기본 구조
- 오늘의 테마
- 핵심 일정 3–5개
- 시간대별 실행표
- 식사·카페·휴식
- 이동·주차·예약
- 피로도와 삭제 순서
- 악천후·지연 대체안

## 5. 편집 원칙
- 장소 나열보다 방문 이유를 먼저 설명한다.
- 동일 장소 설명을 일정표와 장소 해설에서 장문 반복하지 않는다.
- 변동 가능 정보는 본문과 분리해 재확인 대상으로 표시한다.
- Julia의 수영은 선택 일정이며 숙소 선정조건으로 사용하지 않는다.
- Marseille는 Cassis 고정 일정이 아니라 악천후 대체안이다.
- 지도·사진 자리표시자는 Phase 6·7에서 실제 자산으로 교체한다.
