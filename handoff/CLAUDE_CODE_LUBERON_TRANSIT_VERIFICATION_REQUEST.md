# Claude Code 검증 요청 — Luberon 숙박·교통

## 대상

- 브랜치: `codex/luberon-transit`
- 검증 대상: 이 요청서가 포함된 브랜치 최신 커밋
- 검증자는 격리 워크트리에 대상 커밋을 직접 체크아웃하고 코드를 수정하지 않는다.

## 변경 의도

Luberon 원고의 “대중교통이 사실상 없다”는 절대적 표현을 공식 자료와 대조해 바로잡았다. ZOU! 노선은 존재하지만, 농가 숙소에서 여러 마을을 잇는 Day 16–19 일정의 정본은 렌터카다. 차량 장애 때는 전체 일정을 버스로 복제하지 않고 하나의 노선 축으로 축소한다.

## 독립 검증 항목

1. `data/transit-facts.json`의 Luberon 정보가 공식 ZOU! Vaucluse 시간표 및 Pays d’Apt Luberon 관광청 자료와 일치하는지 확인한다.
2. 917(Apt–Gordes–Maubec), 915(Avignon–Apt), 907(Avignon–Cavaillon–Coustellet)의 축이 정확한지 확인한다.
3. 989가 고정 시간표형 일반 노선이 아니라 사전예약형 교통이라는 설명을 확인한다.
4. 99xx 통학 노선을 방문객 비상안에서 제외한 판단이 타당한지 확인한다.
5. Day 16–19 실행 카드의 mode가 각각 `{car}`, `{car, walk}`, `{car, walk}`, `{car, walk}`이며 본문·지역 요약과 모순되지 않는지 확인한다.
6. `region-essentials`의 농가 숙소, 장보기, 주유, 외곽 주차, 일몰 전 귀환 안내가 기존 일정과 충돌하거나 불필요하게 중복되지 않는지 확인한다.
7. 지역 화면 390px·1440px에서 교통 정보, 공식 자료 링크, Day 16–19 링크가 정상 렌더되고 가로 넘침·콘솔 오류가 없는지 확인한다.
8. 사이트·UX·콘텐츠 손실·viewport·PWA 게이트를 실행한다.

## 특별 주의

- 2026년 9월 1일 개편 시간표를 기준으로 보되, 여행 전 재확인 규칙은 유지한다.
- 농가 숙소가 정류장과 연결된다고 추정하지 않는다.
