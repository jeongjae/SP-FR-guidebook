```
## 절대 규칙

1. site/ 를 직접 편집하지 마라. 빌드 산출물이라 다음 빌드에 덮어써진다.
   본문은 source/, 구조·템플릿은 build/build.py, CSS·JS는 build/assets/ 에서 고친다.
2. 런타임 서드파티 의존성을 추가하지 마라. 현재 0개고, 완전 오프라인으로 동작해야 한다.
3. 미확정값을 확정처럼 표시하지 마라. 예약이 아직 안 잠겼다.
   숙소 후보 주소를 확정으로 믿고 이동하는 것이 이 프로젝트 최악의 사고다.
4. 검증 안 된 사실을 쓰지 마라. 현장에서 틀린 정보는 없느니만 못하다.
5. 8월 29일 이후에는 구조를 바꾸지 마라. 여행 중 앱이 바뀌면 안 된다.

```

```
  대표사진 8장이 CC BY-SA 4.0 / CC BY-SA 2.5 / CC BY 2.0 이다.
  source/ASSETS/88_Representative_Public_Photo_Credits_v1.0.md 에 크레딧이 있다.

T9 오프라인 지도 안내
  Organic Maps 는 KML 북마크 임포트와 오프라인 턴바이턴 안내를 지원한다.
  저장소에 이미 도시별 KML 8개가 있다. site/maps/offline.html 에 임포트 절차를 쓰고
  site/maps/kml/ 로 파일을 배포해 직접 다운로드하게 한다.
  자체 오프라인 타일 지도는 구현하지 마라. 용량·라이선스 문제로 폐기된 안이다.
  KML 핀 이름이 한글·프랑스어 혼용이라 인코딩이 깨질 수 있다.
  실기기 검증 전까지는 안내를 확정하지 말고 그 사실을 명시해라.

T8 오프라인 대응
  현재 nav.js 가 장소 사진을 Wikipedia REST API 로 실시간 fetch 한다.
  오프라인에서 사진이 0장이다. 로컬 대표사진을 기본으로 하고 Wikipedia 는
  추가 향상으로만 둔다. navigator.onLine 으로 body.is-offline 을 토글하고
  외부 링크에 .needs-net 을 붙여 비활성화한다. CSS 는 이미 style.css 에 있다.
```
