## 0. 전제 정정

설계 문서 01–03은 "아직 만들지 않은 앱"을 전제로 작성했다. 실제로는 **이미 동작하는 사이트가 존재한다.**

| 확인된 구성 | 규모 |
|---|---|
| 챕터 페이지 | 11개 (01–11) |
| 실행지도 | 8개 |
| 트래커 | 6개 (일정·예약·이동·숙소·대시보드·잠금) |
| 데일리 카드 | 43일 인덱스 |
| 내비게이션 | 상단바 + 드로어 + 검색 + 하단 5탭 + 맨위로 |
| 데이터 | `data.js` 190 KB |

정보구조는 이미 상당히 잘 잡혀 있다. 드로어의 8지역 목록에 체류 기간을 병기한 것, 지도·트래커를 분리한 것, `word-break: keep-all`로 한글 줄바꿈을 처리한 것은 그대로 유지했다.

**따라서 이번 작업은 재설계가 아니라 스타일시트 교체다.** 클래스명·DOM 구조를 하나도 바꾸지 않았으므로 `assets/style.css`만 덮어쓰면 적용된다.

## 1. 문제 진단

### 1.1 야외 가독성 — 가장 큰 문제

이 사이트는 실내 데스크톱 기준으로 잘 만들어졌다. 문제는 **사용처가 야외 주광**이라는 점이다.

| 항목 | 기존 | 문제 |
|---|---|---|
| `--muted: #64748b` on `#faf9f7` | 4.6 : 1 | AA 겨우 통과. 직사광에서 판독 곤란 |
| muted 사용처 | `.card-sub`, `.tl-dates`, `p.note`, `.pl-body p`, `.di-region` | **실질 본문에 캡션 색을 씀** |
| 480px 이하 본문 | 16px → **15px 축소** | 방향이 반대. 작은 화면일수록 야외 확률이 높다 |
| `.pl-body p` | 0.84rem ≈ 13.4px | 장소 설명이 캡션 크기 |
| `.pl-credit` | 10px | 판독 불가 |
| `.bottomnav` 라벨 | 10.5px | 상시 노출 UI 중 가장 작음 |

`--bg: #faf9f7` / `--quote-bg: #f4f1ea`는 따뜻한 크림 계열이다. 프로방스 오후의 황색광에서 흰 종이 대비 반사 대비가 낮아진다.

### 1.2 터치 타깃 미달 — 6개소

한 손으로 걸으면서 쓰는 앱에서 44px 미만은 오탭을 만든다.

| 요소 | 실제 높이 [계산] | 판정 |
|---|---:|---|

| `.sn-days a` | 약 26 px | 심각 |
| `.tl-map` | 약 28 px | 미달 |
| `.related a` | 약 32 px | 미달 |
| `#drawer-close` | 약 34 px | 미달 |
| `nav.tabs a` | 약 34 px | 미달 |
| `.bottomnav a` | 약 44 px | 경계 |

### 1.3 표현 수단 부재

기존 팔레트는 액센트 1색(`#1f4e78`)뿐이다. 다음을 표현할 방법이 없다.

| 필요 | 기존 수단 |
|---|---|
| P0 연결일 경고 (6일) | 없음 |
| 미확정값 구분 | 없음 |
| 8개 지역 구분 | 없음 (전부 같은 파랑) |
| 피로도 5단계 | 없음 |
| 추천등급 5종 | 없음 |

**미확정 표시가 없는 것이 가장 위험하다.** 원본 GeoJSON에는 `status: "후보 — 실제 예약 후 교체"` 핀이 존재한다. 숙소 후보 주소를 확정 주소로 믿고 이동하는 사고가 가능하다.

| # | 위치 | 문제 |
|---|---|---|

## 2. 개선 내역

### 2.1 색상

| 토큰 | 기존 | 변경 | 대비 |
|---|---|---|---:|
| `--bg` | `#faf9f7` | `#EFF2F1` | — |
| `--text` | `#1f2937` | `#0F1A1E` | 15.4 : 1 |
| `--text-2` **(신규)** | — | `#34464D` | 9.1 : 1 |
| `--muted` | `#64748b` | `#5C6D74` | 5.6 : 1 |
| `--accent` | `#1f4e78` | `#153A4E` | — |

`--text-2`를 신설해 **보조 본문과 캡션을 분리**했다. 기존에 `--muted`를 쓰던 `.card-sub`·`.tl-dates`·`p.note`·`.pl-body p`·`.di-region`을 전부 `--text-2`(9.1:1)로 올렸다. `--muted`는 이제 진짜 캡션에만 남는다.

### 2.2 신호색 4종 (신규)

```css
--sig-critical: #9E1B32;  /* P0 연결·최고 리스크 */
--sig-caution:  #7A5B00;  /* 미확정·재확인 필요 */
--sig-steady:   #1F5E45;  /* 확정·완료 */
--sig-rest:     #3A5A9B;  /* 회복일·완충 */
```

장식용이 아니다. 각 색이 하나의 상태만 뜻한다.

순수 적색을 쓰지 않은 이유: 직사광에서 채도가 날아가 주황과 구분되지 않는다.

### 2.3 지역 액센트 8종 (신규)

```css
--acc-bcn: #8C3A2E;  --acc-gir: #A8521F;
--acc-nce: #0E6E86;  --acc-aix: #4F6129;
--acc-lub: #92650F;  --acc-avn: #63447A;
--acc-lyo: #7A2E45;  --acc-par: #2F4A6B;
```

**적용 방식이 중요하다.** 색을 배경에 쓰지 않고 **좌측 리본(4–5px)** 으로만 쓴다. 배경색으로 쓰면 8개 파스텔 카드가 되어 야외 대비가 무너진다.

타임라인 8항목은 `:nth-child()`로 자동 부여되므로 HTML 수정이 필요 없다.
드로어의 지역 링크는 `href$="04.html"` 선택자로 자동 부여된다.

### 2.4 타이포

| 항목 | 기존 | 변경 |
|---|---|---|
| 본문 | 16px (480px 이하 15px) | **17px (480px 이하 17.5px)** |
| 표 | 0.88rem | 0.95rem |
| 장소 설명 | 0.84rem | 0.9rem |
| 사진 크레딧 | 10px | 0.7rem + 32px 높이 |
| 하단 탭 라벨 | 10.5px | 0.7rem |
| 숫자 | 비례 | **`font-variant-numeric: tabular-nums`** |

등폭 숫자는 시각표·날짜에서 필수다. `9/1`과 `10/10`의 자릿수가 정렬되어야 목록 스캔이 된다.

글자 크기 4단계 훅을 추가했다: `data-size="s|l|xl"`. `nav.js`에서 body에 속성만 붙이면 동작한다.

### 2.5 터치 타깃

`--tap: 44px` 변수를 도입하고 미달 요소 전부에 `min-height`를 부여했다.

| 요소 | 기존 | 변경 |
|---|---:|---:|
| `.pl-credit` | 16 px | 32 px |
| `.sn-days a` | 26 px | 38 px |
| `.tl-map` | 28 px | 40 px |
| `.related a` | 32 px | 44 px |
| `#drawer-close` | 34 px | 44 px |
| `nav.tabs a` | 34 px | 44 px |
| `.bottomnav a` | 44 px | 56 px |
| `#menu-btn` | 32 px | 44 px |

`.pl-credit`은 사진 우하단 모서리에 붙여 터치 영역을 넓히면서도 사진을 덜 가리게 했다.

### 2.6 하단 탭바 재설계

| 항목 | 기존 | 변경 |
|---|---|---|
| 배경 | `--surface` (흰색) | `--accent` (짙은 청색) |
| 활성 표시 | 색상만 | 색상 + **상단 3px 인디케이터** |
| 높이 | 약 44px | 56px |
| 탭 구성 | 홈·일정·오늘·지도·트래커 | **오늘**·일정·**지역**·지도·트래커 |

탭 구성을 바꾼 이유:

- **홈 제거** — 홈은 8구간 타임라인이고, 일정 탭과 성격이 겹친다
- **오늘을 첫 칸으로** — 하루 8–15회 진입하는 화면이다
- **지역 추가** — 8개 챕터가 드로어 뒤에만 있었다. 하루 1–3회 쓰는 것을 2뎁스에 두면 안 된다

> 탭 변경은 HTML 수정이 필요하다. CSS만 적용하면 기존 5탭이 새 스타일로 나온다. 순서 변경은 선택 사항이다.

### 2.7 이모지 → 기하 문자

`🏠📅📍🗺️📋` → `◉ ▤ ◇ ⌖ ▦`

이모지는 플랫폼마다 다르게 렌더되고 색을 통제할 수 없어 짙은 탭바 위에서 대비가 보장되지 않는다. 기하 문자는 텍스트 색을 따르므로 활성·비활성 상태가 정확히 표현된다.

### 2.8 신규 컴포넌트 5종

| 클래스 | 용도 |
|---|---|
| `.badge-p0` / `.badge-pending` / `.badge-done` / `.badge-rest` | 상태 배지 |
| `.pending` | 미확정 카드 — 점선 테두리 + 배경 틴트 |
| `.fatigue[data-v="1..5"]` | 피로도 막대 + 숫자 |
| `.grade-essential` 외 4종 | 추천등급 — **모양(■●○◇▨)으로 구분** |
| `.daily-item.is-p0` | 43일 카드의 P0 표시 |

전부 **색을 제거해도 판독 가능**하도록 설계했다. 피로도는 막대 개수와 숫자, 등급은 도형이 정보를 담는다.

### 2.9 코드 정리

| # | 조치 |
|---|---|
| 1 | 타임라인 매직넘버 제거 → `--rail-x` 변수 하나로 통합. 480px 재지정 삭제 |
| 2 | `.card:hover`의 `transform` 제거 |
| 3 | `prefers-reduced-motion` 전역 대응 추가 |
| 4 | `:focus-visible` 전역 스타일 추가 (3px 외곽선) |
| 5 | `[data-theme]` 수동 다크 토글 훅 추가 |
| 6 | `body.is-offline .needs-net` — 오프라인 시 외부 링크 자동 비활성 훅 |
| 7 | 표 짝수행 줄무늬 추가 |
| 8 | `@media print` 규칙 추가 |

### 2.10 모서리 반경

12px → 4px로 통일했다. 큰 반경은 소비자 앱 언어이고, 이 도구는 시각표·감사표에 가깝다. 정보 밀도가 높은 표와 12px 라운드 카드는 어울리지 않는다.

## 3. 적용 방법

### 3.1 CSS만 교체 (즉시)

```
assets/style.css  ←  첨부된 style.css 로 덮어쓰기
```

클래스명·DOM 구조를 바꾸지 않았으므로 전 페이지에 그대로 적용된다.

### 3.2 HTML 수정이 필요한 항목 (선택)

| # | 항목 | 작업량 |
|---|---|---|
| 1 | 하단 탭 순서·구성 변경 | 전 페이지 `nav.bottomnav` 블록 교체 |
| 2 | 이모지 → 기하 문자 | 위와 동시 |
| 3 | 미확정 숙소에 `class="pending"` | 숙소 카드 생성 로직 |
| 4 | P0 6일에 `class="is-p0"` + 배지 | 데일리 인덱스 생성 로직 |
| 5 | 피로도 마크업 | 챕터 생성 로직 |
| 6 | 사진 저작자 표시 페이지 | 신규 1페이지 (CC 라이선스 의무) |

1·2번은 정적 치환이라 금방 된다. 3–5번은 페이지 생성 스크립트 수정이 필요하다.

### 3.3 확인

`index_preview.html`을 브라우저에서 열면 CSS가 인라인되어 있어 단독으로 렌더된다. 신규 컴포넌트 5종도 한 화면에 모아 뒀다.

## 5. 유지한 것

개선안이 **바꾸지 않은** 기존 판단들이다. 전부 옳다고 봤다.

- 드로어 + 하단탭 이중 내비게이션
- 8지역 목록에 체류 기간 병기
- `word-break: keep-all` (한글 어절 단위 줄바꿈)
- `scroll-padding-top` (앵커 이동 시 sticky 헤더 보정)
- `env(safe-area-inset-bottom)` 처리
- 챕터 서브내비의 Layer 필터 + Day 칩
- 표 `overflow-x` 래퍼
- `main { max-width: 46rem }`
- 트래커를 별도 섹션으로 분리한 구조
