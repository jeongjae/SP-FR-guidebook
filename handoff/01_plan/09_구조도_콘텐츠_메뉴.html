4. 챕터 내부 콘텐츠 구조

11대 카테고리 골격은 그대로 유지한다. 8챕터에 일관 적용된 이 구조가 이 사이트 최대 자산이다. 바뀌는 것은 한 페이지 안의 섹션이던 것이 독립 페이지가 된다는 점뿐이다.

Chapter 05 · Girona
│
├─ 허브 index.html
│   ├ 지역소개  Editor's Verdict · 다섯 개의 층 · 3박이 하는 일
│   ├ 일정 카드 4       → day-N.html

│   ├ 무엇인가         배경·역사·의미  서술체
│   ├ 핵심             이 장소를 보는 단 하나의 축
│   ├ 관람 요령        번호 매긴 실행 지시  인용 블록
│   ├ 사진             페이지가 분리돼 자유롭게 삽입 가능
│   ├ 상호 링크        "팔스는 복원, 여기는 원형" → 팔스 페이지
│   └ 실용             요금·소요·주의  재확인 배지
│
└─ 주제
    ├ 먹거리      요리 이해 → 주문할 것 → 날짜별 → 시장
    ├ 교통        국경 → 통행료 → 연료 → 운전 → 주차
    ├ 경비        구조 → 입장료 → 절감 → 결제
    └ 대안 루트   우선순위표 → 개별 (왜 뺐나 / 넣는 법)
왜 분할하는가 — 기존은 큰 마크다운 1개 → HTML 1장 + 앵커였다. 대성당에 사진 5장과 공식 링크를 붙이면 챕터 전체가 무거워진다. 분할하면 각 방문지가 독립 URL을 가지므로 자유롭게 보강할 수 있고, 상호 링크도 가능해진다.

관리 부담은 늘지 않는다. authoring 파일은 5개고 output만 20장이다. places.md 하나를 편집하면 방문지 페이지 11장이 나온다.
