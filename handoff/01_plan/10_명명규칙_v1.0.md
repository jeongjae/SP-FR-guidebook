# 명명 규칙 (Naming Convention) — 필수 준수

**적용 범위** 메뉴 라벨, 페이지 제목, 헤딩, URL 슬러그, 빵부스러기, 검색 인덱스 전부

---

## 원칙

**번호로 이름을 짓지 않는다. 지명과 내용으로 짓는다.**

날짜와 일자 번호는 예외다. 실제 시간 순서를 나타내므로 정보를 담는다.

---

## 금지

| 금지 | 예 |
|---|---|
| 챕터 번호 | `04. 바르셀로나`, `Chapter 05.`, `챕터 5` |
| 섹션 번호 | `10.2 유대인 지구`, `5. 숙소 전략`, `13.4 추천 식당 역할표` |
| 항목 원문자 | `① 창조의 태피스트리`, `관람 요령 ㉒` |
| 번호 URL | `chapters/05.html`, `chapters/05/` |
| 의미 없는 순번 라벨 | 카드 아이브로우의 `01` `02` `03` |

## 허용

| 허용 | 예 | 이유 |
|---|---|---|
| 전체 여행 Day 번호 | `Day 16 · 9월 13일 일` | 43일 중 위치를 알려준다 |
| 날짜 | `9월 2일 수` | 시간 정보 |
| 지명 | `Girona`, `Nice`, `Peratallada` | 대상 자체의 이름 |
| 실제 순서가 있는 목록 | 관람 순서 1→2→3, 대안 우선순위 표 | 순서가 정보다 |
| 사실로서의 숫자 | `23m`, `1492년`, `€12`, `3박` | 내용 |

---

## Day 번호는 전체 여행 기준으로 통일한다

**현재 사이트는 챕터 로컬 번호를 쓴다.** Paris 챕터의 `Day 16`이 실제로는 전체 Day 43이다. 데일리 페이지(`daily/day-43.html`)와 어긋나 혼란을 만든다.

| | 현재 (챕터 로컬) | 변경 (전체 기준) |
|---|---|---|
| Girona 첫날 | Day 1 | **Day 4 · 9월 1일 화** |
| Paris 마지막날 | Day 16 | **Day 43 · 10월 10일 토** |

**표기 형식** `Day 4 · 9월 1일 화` — Day 번호, 가운뎃점, 날짜, 요일.

## URL 슬러그

챕터 번호 대신 지명 슬러그를 쓴다.

| 기존 | 변경 |
|---|---|
| `chapters/04.html` | `chapters/barcelona/` |
| `chapters/05.html` | `chapters/girona/` |
| `chapters/06.html` | `chapters/nice/` |
| `chapters/07.html` | `chapters/aix/` |
| `chapters/08.html` | `chapters/luberon/` |
| `chapters/09.html` | `chapters/avignon/` |
| `chapters/10.html` | `chapters/lyon/` |
| `chapters/11.html` | `chapters/paris/` |
| `chapters/01.html` | `chapters/how-to-use.html` |
| `chapters/02.html` | `chapters/highlights.html` |
| `chapters/03.html` | `chapters/itinerary.html` |

챕터 내부 페이지:

```
chapters/girona/index.html          허브
chapters/girona/day-04.html         일자 (전체 Day 번호, 2자리)
chapters/girona/place-cathedral.html 방문지
chapters/girona/food.html           주제
```

**기존 번호 URL은 리다이렉트를 남긴다.** 사용자가 즐겨찾기했을 수 있고, 검색 인덱스와 드로어 링크가 걸려 있다.

## 라벨 예시

| 위치 | 금지 | 권장 |
|---|---|---|
| 드로어 | `04 Barcelona · Sitges` | `Barcelona · Sitges` |
| 페이지 제목 | `Chapter 05. 지로나·콜리우르` | `Girona · Collioure · Empordà` |
| 아이브로우 | `CHAPTER 05 · GIRONA` | `GIRONA` |
| 헤딩 | `## 10.2 유대인 지구` | `## Call — 유대인 지구` |
| 헤딩 | `### ① 창조의 태피스트리` | `### 창조의 태피스트리` |
| 인용 블록 | `> **관람 요령 ⑮**` | `> **복제화 앞에 서서 겹쳐 보라**` |
| 카드 | 아이브로우 `05` | 아이브로우 생략 또는 `9월 1일 화` |

**인용 블록 제목이 중요하다.** `관람 요령 ①②③`은 번호가 정보를 담지 않는다. 대신 **그 요령의 내용을 제목으로 쓴다.** 목차에서 스캔이 되고, 현장에서 필요한 항목만 골라 읽을 수 있다.

## 검증

```bash
# 챕터 번호 잔존
grep -rnE "(Chapter [0-9]+|챕터 ?[0-9]+|^[0-9]{2}\. )" site/ | grep -v "Day " | wc -l   # 0

# 헤딩 섹션 번호
grep -rnoE "<h[2-4][^>]*>\s*[0-9]+([.)]|\.[0-9]+)" site/ | wc -l                        # 0

# 원문자
grep -rno "[①-⑳㉑-㉟]" site/ | wc -l                                                   # 0

# Day 번호 전역 통일 — Paris 마지막날이 Day 43
grep -c "Day 43" site/chapters/paris/day-43.html                                        # ≥1
```
