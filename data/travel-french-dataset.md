# Travel French Dataset v1.0

- 총 **120개** 표현
- 표기 순서: 프랑스어 / 한국어 의미 / 한국어식 발음 근사치 / 사용 메모
- 한국어식 발음은 여행자가 빠르게 읽기 위한 보조 표기이며 정확한 음성학 표기가 아니다.
- 데이터 정본(SOT)은 `TRAVEL_FRENCH_PHRASES_v1.0.json`으로 한다.
