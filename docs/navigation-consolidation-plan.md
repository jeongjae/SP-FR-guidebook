  ("일정"류는 하단탭 1곳, 주제 축은 색인일 뿐 본문 없음 — CLAUDE.md 원칙 준수 확인)
- 같은 페이지로 가는 이름 다른 메뉴: **없음**
- orphan: 빌드 링크 가드(check_links)가 전 href 실존을 강제, 데일리·장소·주제
  전 페이지가 좌표 바 또는 서브내비로 도달 가능. 미도달 페이지 없음.
