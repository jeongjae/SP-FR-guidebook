## 3. 시사점

1. **오염 범위는 Phase 3B 전체 + Phase 4다.** Phase 2(Nice)만 "원문 편집" 방식으로 수행됐고, 3B부터 "재생성" 방식으로 바뀌었다. 3B의 "68~73% 고효율 압축"은 사실상 재생성의 부산물이었다.
2. **QA 보고서의 정량 지표는 전부 통과하면서 이 손상이 발생했다.** 스키마 14개 H2, 레지스트리 매칭, 빌드, 테스트, 링크 — 모두 PASS다. 현재 검증 체계는 "구조"만 보고 "사실 보존"을 보지 않는다.
3. **main은 완전한 정본으로 남아 있다.** 모든 유실 사실값은 main에서 복구 가능하다.
4. 3B가 Girona Day 5–6에 채운 피로도 수치는 main 원고에 근거가 없는 창작값이다 (main 주석: "Girona 원고 어디에도 값이 없음"). 재작업 시 사용자 확인 필요 항목이다.
