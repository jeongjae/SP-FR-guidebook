# Map privacy policy

## 공개 금지

- 개인 숙소의 정확 주소, 정밀 좌표, 예약 URL, Google Place ID
- 개인 일정으로부터 숙소 위치를 역산할 수 있는 출발·복귀 링크
- 공개 지도에 필요 없는 예약번호와 체크인 세부정보

## 공개 표현

개인 숙소는 도시 또는 권역 수준의 근사 좌표, `private: true`, `approximate: true`로 표시한다. 장소 열기·현 위치 길찾기·숙소 복귀 링크는 만들지 않는다. private 출발 구간은 origin을 생략해 사용자의 현재 위치에서 공용 목적지로 안내한다.

이번 작업은 현재 작업 트리의 Markdown, GeoJSON, KML, HTML, daily JSON, XLSX에서 개인 숙소의 정확 주소·정밀 좌표·지도 URL을 제거했다. XLSX는 ZIP 내부 worksheet XML만 치환해 다른 workbook 항목을 보존했다.

중요: 현재 파일을 고치는 작업은 Git 과거 커밋을 지우지 않는다. 저장소가 이미 공개되었거나 공개 예정이라면 별도 승인 아래 기록 재작성과 기존 배포물·캐시 삭제, 필요 시 노출 URL 폐기를 수행해야 한다. 이 작업은 이번 파일럿 범위에 포함하지 않았다.
