## 1. 방식 — 이동·삭제·헤딩·연결문만

재생성을 원천 차단하기 위해 **조립 스크립트로 main 원문의 행 범위를 그대로 추출해 재배치**했다. 스크립트는 `L(a,b)` 로 main의 a~b행을 글자 단위 그대로 가져오며, 새로 타이핑한 것은 H2·H3 헤딩과 표 헤더뿐이다. 연결문은 작성하지 않았다 — 지시 §1의 "문단당 1문장" 여유를 쓰지 않고 이동만으로 골격이 구성됐다.

스크립트: `scratchpad/build_lyon.py` (세션 산출물, 저장소에는 결과물만 커밋).

## 2. 사실값 행 글자 단위 일치 — 전수 대조

정규식(`€\d`·`\d:\d\d`·`+33`·6자리 예약코드·거리/시간 수치·연도)으로 **사실값을 담은 모든 행**을 뽑아 main 원문 행 집합과 대조했다.

```
사실값 포함 행 중 main 미일치: 9건
```

9건 전부 텍스트는 main에 존재하며, 형태만 바뀐 것이다.

| 유형 | 건수 | 내역 |
|---|---:|---|
| `{{VISUAL:VIS-MAP-055~059}}` 자리표시자 | 5 | main의 `### {{VISUAL:…}} 제목 + 설명` 블록에서 **제목·설명을 삭제하고 토큰만** Day 섹션 '오늘 지도'로 이동. ID는 main 그대로 |
| 표 셀 → 리스트 항목 | 2 | 12A 표·우천 대체표의 셀 텍스트를 Day 섹션 '대안 대책'으로 이동 (셀 구분자만 제거, 문자열 동일) |
| 피로도 행 후반부 → '오늘의 결론' | 2 | main `**오늘의 피로도: 4/5.** 예상 보행 8–10km…` 의 뒷문장을 결론 줄로 이동 |

`grep` 재현: 위 4개 문자열 모두 `git show main:…10_Lyon_v2.0.md` 에 존재 확인.
