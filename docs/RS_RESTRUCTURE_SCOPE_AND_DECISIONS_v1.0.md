## 2. Daily 43일 정본 확인 (중요)

Daily 본문의 정본은 **지역 챕터 원고의 Day 절**이다 (별도 파일 아님).
`build_split_chapter()` 가 `schedule` 카테고리의 Day 절을 `daily/day-NN.html` 로 보내고,
실행 요약은 `OPERATIONS/100` 감사표에서 온다. 따라서 "Region 에서 날짜별 시간표
제거"(계획서 Phase 2 작업 2)는 **파일에서 삭제가 아니라, 챕터 파일 안에 남기되 Region
페이지에 렌더되지 않는 현행 구조를 유지·정리하는 것**이다. 현행 빌드가 이미 Day 절을
Daily 로만 렌더하므로, 실제 제거 대상은 Day 절 **밖에** 남은 날짜별 중복(요약표 2~3중,
날짜별 전략표, Pass B 감사 등)이다.
