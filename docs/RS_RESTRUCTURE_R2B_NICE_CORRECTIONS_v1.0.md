## 2. 불합격 항목

### 2.1 "복원"으로 보고된 신규 창작 4건 (핵심 문제)

보고서 대조표 2~5행이 "복원 PASS"로 제시한 요금들은 **main에도, 오염 브랜치에도 존재하지 않는다.** R2가 새로 써 넣은 값이다. diff로 실증했다.

| 보고서 주장 | 실제 |
|---|---|
| Villefranche TER 편도 €2.30 "복원" | main 0건 · 브랜치 0건 → **신규 창작** |
| Monaco CAM 1·2번 €2.00 / Pass 24h €5.50 "복원" | main 0건 · 브랜치 0건 → **신규 창작** |
| Èze 82번 버스 편도 €1.70 "복원" | main 0건 · 브랜치 0건 → **신규 창작 + 정본 모순** |
| Forville 카페 에스프레소 €1.80–2.20 "복원" | main 0건 → **신규 창작** |

특히 Èze €1.70은 main 정본과 **모순**된다. main의 복수 출처 확인 행: "Lignes d'Azur 단발권 **€1.80** (1시간 내 버스·트램 환승 무제한)" — 82번은 Lignes d'Azur 노선이므로 단발권 체계를 따른다. 창작값이 검증된 정본을 덮어쓴 것이다.

재작업 원칙 §1 "연결문에 사실값 포함 금지"와 "변동정보 무근거 갱신 금지"의 정면 위반이며, 이를 "복원"이라 보고한 것은 **보고 왜곡**이다. 실제로 있었던 일을 그대로 쓰라: "main에 없는 요금 4건을 외부 지식으로 추가했다"가 사실이다.

### 2.2 지시된 복원 4건은 수행되지 않음

검수 보고서가 명시한 유실 요금 — 트램 10회권 **€12.60**, 월정기 **€40**, **€700–1,000** 선정범위, **€35** — 는 여전히 0건이다. 지시가 요구한 복원 대신 다른 것이 "복원"으로 보고됐다.

### 2.3 습니다체 처리 방식 위반 (경미)

지시는 "main 원문 문장으로 환원, 대응 문장이 없으면 삭제"였다. 실제로는 어미만 평서문으로 **전환**했다. 표본 검증 결과 엘리베이터 건(무료 공공 엘리베이터·5분)은 main 211~226행과 사실이 일치해 실해는 없으나, 방식 자체는 지시 위반이다.

## 3. R2b 시정 지시

### 3.1 창작 요금 4건 처리

1. **Èze €1.70 삭제** → main 정본의 요금 체계로 대체: "Lignes d'Azur 단발권 €1.80" (main 원문 행 그대로, `{{badge:pending}}` 유지)
2. **Monaco CAM €2.00/€5.50, Villefranche TER €2.30, 에스프레소 €1.80–2.20**: 각각 다음 중 하나로 처리하고 선택 사유를 보고하라.
   * (a) 요금 숫자만 제거하고 교통수단 안내 문장 유지 (사실값 없는 연결문화)

   * 출처를 제시할 수 없으면 (a)만 허용된다

### 3.2 지시된 복원 수행

1. main 1360행의 요금 체계 행(단발권 €1.80 · 10회권 €12.60 · 1일권 €5 · 7일권 €15 · 월정기 €40 · 각인 규정)을 **원문 그대로** `## 공식 확인 정보와 재확인 대상` 절에 복원
2. €700–1,000 선정범위와 €35: 복원 또는 삭제-정당 판정을 **행 단위로** 보고하라. 선정 당시 계획범위는 폐기 기록으로 보아 삭제가 정당할 수 있다 — 그렇다면 그렇게 명시하면 된다. 근거 없는 누락만 불허한다.

### 3.3 습니다체 5곳 사후 증빙

전환된 5개 문장 각각에 대해 **main 근거 행 번호를 인용**해 사실 일치를 증명하라. 근거 행이 없는 문장은 삭제하라. (엘리베이터 건은 검수에서 이미 확인됨 — 나머지 4곳)
