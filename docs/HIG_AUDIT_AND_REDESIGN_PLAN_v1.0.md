## 0. 요약 — 기계 검사는 이미 전부 통과다

```
python3 build/hig_check.py --all
→ 266쪽 × 2폭 × 라이트/다크 — 터치타깃 · 글자크기 · 명암비 ·
  안전영역 · 리플로 · 뷰포트 이상 없음
```

44pt 타깃, 11px 하한, 본문 7:1 / 크롬 4.5:1, `safe-area-inset`, 320px 리플로,
`viewport-fit=cover` — **여섯 항목 모두 266쪽 전부 통과한다.** 다크모드까지
포함해서다. 이 층에서 고칠 것은 없다.

그래서 이 문서는 기계가 못 보는 층만 다룬다. HIG 가 원칙으로만 말하는
**명료함(Clarity) · 위계(Hierarchy) · 일관성(Consistency) · 콘텐츠 우선**이고,
전부 실제 계측값을 근거로 적었다. 추정으로 적은 항목은 없다.

발견 17건. 등급은 **현장에서 잘못 읽을 위험**을 기준으로 매겼다.

| 등급 | 건수 | 뜻 |

| 🔴 높음 | 5 | 현장에서 정보를 못 읽거나 틀리게 읽는다 |

페이지 제목은 상단바에만 있고, 본문 구조는 h2 부터 시작한다.

| | |

## E. 색·토큰 — 의도한 디자인이 안 나가고 있다 ⚪

### E-1. 정의되지 않은 CSS 토큰 4종을 `var()` 로 참조한다

| 토큰 | 참조하는 셀렉터 | 실제 결과 |
|---|---|---|
| `--shadow-1` | `.itinerary-table tbody tr`, `.guide-photo`(114쪽) | 선언 전체가 무효 → **그림자 없음** |
| `--surface-2` | `.guidebook-image .media-zoom`, `.media-fallback` | 바탕 미적용 |
| `--sig-es-ink` | `.dem-list-copy small` | 신호색 미적용(글자색 상속) |
| `--marker-color` | `.dem-legend i`, `.dem-marker-icon` | 값이 CSS·HTML·JS 어디에도 없음 |

`var()` 가 정의되지 않으면 **그 선언만 무시되는 게 아니라 계산 시점에
무효**가 되어 초깃값으로 떨어진다. 즉 일정표 카드와 사진 프레임 114쪽은
입체감을 갖도록 설계됐지만 지금 평평하게 나간다.

| | |
|---|---|
| **Before** | 토큰 4종이 유령이다. 빌드도 HIG 검사도 이걸 못 잡는다. |
| **After** | 토큰을 정의하거나 참조를 걷어낸다. **미정의 토큰 참조를 빌드 가드에 추가한다** — 정규식 한 줄이면 다시는 새지 않는다. |

### E-2. 죽은 CSS 클래스 33종 ⚪

`site/` 의 어느 HTML·JS 에도 안 나오는 클래스가 33종, 그중 14종이
`.dem-*` (옛 일자 실행지도 컴포넌트) 한 덩어리다. `style.css` 는 94KB 다.

### E-3. 지역 목록에 국가가 안 보인다 🟡

`CLAUDE.md`: *"Day 7 에 국경을 넘고 그 뒤로 시장 요일·공휴일·긴급번호·언어가
바뀐다. 장식이 아니라 그 정보다."*

| | |
|---|---|
| **Before** | 국기 띠는 일자 페이지에만 있다. `regions.html` 의 8개 거점 카드에는 어디가 스페인이고 어디가 프랑스인지 표시가 없다. 여행 전체를 조망하는 화면에 국경이 없다. |

## G. 컨트롤 ⚪

### G-1. 홈에 뒤로가기 버튼이 뜬다

`nav.js` 가 `history.length > 1` 만 본다. 홈에서 아무 페이지나 들어갔다
돌아오면 홈에도 `‹` 가 남는다. 홈은 계층의 뿌리라 뒤로 갈 곳이 없다.
→ 홈에서는 숨긴다.

### G-2. `오늘` 탭만 실제 URL 이 없다

5개 탭 중 4개는 URL, `오늘` 만 `href="#"` 이고 JS 가 그날 카드를 연다.
JS 가 죽으면 탭 하나가 아무 데도 가지 않는다.
→ `daily/index.html` 을 기본 `href` 로 두고 JS 가 오늘 카드로 덮어쓴다.

### G-3. 사진 크레딧이 원문 URL 을 본문에 푼다

> Photo: Jean-Marc Rosier (de/from http://www.cjrosier.com +
> http://www.gordes-immobilier.com ) · CC BY-SA 3.0

### 이 진단이 확인하지 않은 것

기계 검사는 **터치타깃·글자크기·명암비·안전영역·리플로·뷰포트** 여섯 가지만
본다. 위 A~G 는 전부 실제 렌더 계측과 소스 대조로 확인했지만,
명료함·경의·깊이 같은 원칙 자체가 충족됐는지는 **여전히 사람이 판단해야 한다.**
이 문서를 근거로 "HIG 를 만족한다"고 말하지 않는다 — 검사한 항목만 보고한다.
