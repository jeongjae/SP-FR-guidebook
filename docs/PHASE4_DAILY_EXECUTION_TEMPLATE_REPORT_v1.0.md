# Phase 4 — 43일 실행 일정·데일리 템플릿 개편 보고서

## 결론

43개 데일리 페이지의 공통 순서를 `핵심 실행 → 출발·완충 → 즉시 행동 → 시간표 → 상세 정보 → 보관용 카드`로 통일했다. 1080×1920 카드 이미지는 콘텐츠를 삭제하지 않고 페이지 하단의 접힌 보관 영역으로 옮겨, 첫 화면의 스크롤 압박을 제거했다.

## 사용자 화면 변경

- 제목 아래에 `핵심 실행`, `권장 출발`, `완충` 3개 필드를 고정 노출한다.
- 챕터 일정과 해당 지역 실행지도를 즉시 행동 버튼으로 놓았다.
- 시간표를 카드 이미지보다 앞으로 옮겼다.
- 피로도·이 날의 장소·메모는 실행 흐름에 이어서 배치했다.
- 리스크·우선 삭제·대체안·식사·잠금은 `상세 실행 확인`으로 접었다.
- 오프라인 지도·전체 목록과 보관용 모바일 카드는 페이지 하단으로 이동했다.
- 43일 목록을 8개 여행 거점으로 묶고, 각 날의 핵심 실행을 목록에서 바로 읽게 했다.
- 대안이 없는 교통 연결일 6일은 빨간 왼쪽 표시로 구분했다.

## 회귀 가드

`build/build.py` 내 `check_phase4_daily_guards()`가 다음을 강제한다.

- Day 1–43 페이지의 실행 요약·즉시 행동·시간표·접힌 카드 존재
- 실행 요약 → 시간표 → 카드 순서
- 카드 이미지의 첫 화면 직접 노출 금지
- 일정 목록의 8개 지역, 43개 일자, 43개 핵심 실행 요약

HIG 터치 타깃 검사 대상에 즉시 행동 버튼과 접힌 영역 요약을 추가했다.
