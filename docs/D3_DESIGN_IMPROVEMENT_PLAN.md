## 3. ★ 확인이 필요한 것 — 내 판독으로는 대상이 갈린다

### 3-1. `전체 일정`·데일리 카드의 `삭제` — 좌표 바인가, 서브내비인가

| 페이지 | 주석 좌표 | 그 행에 있는 것 |
|---|---|---|
| p2 `daily/index.html` | (1028, 77) | **좌표 바** (`일정 43일` / `지역 8곳` / `주제 분류·상태`) |
| p7 `daily/day-03.html` | (866, 65) | **서브내비 날짜 칩** (8/29 8/30 8/31 …) 과 좌표 바가 겹친다 |

**왜 그냥 지우지 않았나.** CLAUDE.md 가 좌표 바를 **L1 내비게이션**으로 규정하고,
"메뉴를 지우기 전에는 링크 그래프로 확인한다 — 그 메뉴로만 갈 수 있는 곳이 남아 있으면
길이 끊긴다"고 못박고 있다. 좌표 바는 축 사이를 건너뛰는 유일한 경로다.

**질문 —** 지우려는 것이
ⓐ 좌표 바(일정·지역·주제 칩) 인가
ⓑ 데일리 카드 상단의 날짜 칩 스트립(8/29 8/30 …) 인가
ⓒ 둘 다인가?

### 3-2. `가이드` 화면의 `삭제` (p3, 좌표 1068·184)
그 행에는 지역 카드 그리드의 첫 줄만 있다. 카드를 지우라는 뜻일 리는 없다.
후보는 ⓐ 카드 안의 `실행지도`·`첫날 카드` 버튼 ⓑ 카드 위 설명문
("8개 거점을 이동 순서대로 놓았다…") 둘이다. **어느 쪽인가?**

### 3-3. p5 "이 세 메뉴는 통합하고 중복 내용 삭제"
주석 좌표가 (53, 208) 로 챕터 본문 왼쪽 여백이라 어느 탭을 가리키는지 특정되지 않는다.
현재 주제 서브내비는 **10개**다.
```
허브 · 지역소개 · 여행정보 · 먹거리 · 교통 · 숙박 · 예약 · 경비 · 여행팁 · 부록
```
p6 이 재구성하는 것이 **지역소개 · 숙박 · 여행정보** 셋이므로 그 셋으로 읽었는데,
p6 은 "통합"이 아니라 각각을 고치라는 지시다. **어느 셋인가?**
(후보: `예약`+`경비`+`부록` 처럼 관리용 탭 셋일 수도 있다.)

### 3-4. p7 "여행 '장소 카드'를 나열"
데일리 카드의 어느 블록을 장소 카드 목록으로 바꾸라는 것인지 — 현재 `오늘의 주요 장소`
가 이미 사진 카드 3개를 보여준다. **이걸 늘리라는 것인가, 다른 블록을 바꾸라는 것인가?**

### 3-5. 2-4 의 적용 범위
Barcelona 만인가, 8개 챕터 전부인가.

## 4. 별도 판단이 필요한 큰 변경

### 4-1. 8개 챕터 동시 구조 변경 (2-4·2-5·2-6)
p6 은 Barcelona 를 예로 들었지만 같은 구조가 8개 챕터에 반복된다. 한 챕터만 바꾸면
**챕터끼리 구조가 달라진다** — 현장에서 "이 챕터엔 왜 없지"가 된다. 전부 바꾸거나
전부 두거나다.

**규모 추정** — 렌더러 3개(`about` · `stay` · `places`) 수정 + 원고 8개 파일의
해당 섹션 정리. 빌드 가드가 Day 섹션·장소 레지스트리·토큰을 함께 보므로
회귀 위험이 낮지는 않다.

### 4-2. 출발까지 11일이라는 제약
지금 사이트는 **G1·G4·G5 PASS · 빌드 335p · HIG 통과** 상태로 배포돼 있다.
구조 변경은 이 상태를 흔든다. **권고 — 2-1·2-2·2-3(작고 독립적인 것)을 먼저 넣고,
2-4~2-6(챕터 구조)은 §3 답을 받은 뒤 한 번에 한다.**

## 5. 작업 순서 (§3 답을 받으면)

```
1차 (즉시, 위험 낮음)   2-1 홈 카드 · 2-2 부록 줄 · 2-3 부제        → 빌드·HIG·가드 → 배포
2차 (§3 답 후)          3-1·3-2 삭제 대상 확정분                    → 링크 그래프 확인 필수
3차 (구조)              2-4 지역소개 정리 → 2-5 숙박 → 2-6 장소 카드 통합
                        8개 챕터 동시 적용. 각 단계마다 가드 전체 실행
```

각 차수마다 `python3 build/build.py && python3 build/guards/run_all.py` 를 돌리고,
통과하지 못하면 커밋하지 않는다.

**2026-08-18 부터 HIG 자동검사와 마크업 고정 가드 2종(phase3 내비·phase4 데일리)이
없다.** 개편의 걸림돌을 걷어낸 결정이지만, 그만큼 터치타깃·명암비·탭 구성·43일 카드
전수 렌더는 **사람이 직접 확인해야 한다.**
