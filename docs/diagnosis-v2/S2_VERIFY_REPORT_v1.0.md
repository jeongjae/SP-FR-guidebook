## 3. 이번 세션에 고친 것

### G1 파서 (`build/guards/guard_weekday.py`)
휴관 요일 추출기가 **영업시간 나열을 휴관으로 읽고 있었다.** `연중무휴 — 월–금 09:00–20:00`
같은 값에서 월·금·토·일을 전부 휴관 요일로 뽑았다. 조사 결과를 그대로 적재했다면
오탐이 쏟아졌을 것이다. 요일 뒤에 휴관 표현(`휴관|휴무|휴장|폐관…`)이 직접 붙은 것만
채택하도록 바꾸고, `공휴일`의 `일`·`12월 25일`의 `월`·`일` 을 요일로 오독하지 않도록
앞글자가 한글이거나 숫자면 배제했다. 13개 케이스로 검증했다.

### place-days 매핑 (`build/build_place_days.py`)
