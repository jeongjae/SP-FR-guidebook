# 상용 가이드북 개편 — 정보구조 v1.0

기준 커밋 `c274d42` · 2026-08-06. **현행 구조를 실측으로 기술하고, 개편이 바꾸는
것과 안 바꾸는 것을 구분한다.** 미결 사항은 결정 로그 ID 로 표시.

## 1. 축 구조 (변경 없음)

콘텐츠 원자는 '장소', 하루는 `daily/day-NN.html` 단일 정본, 축(일자·지역·주제)은
색인이며 본문을 갖지 않는다. — CLAUDE.md 원칙 그대로 유지한다.

```text
L0 하단탭   오늘 · 일정 · 지역 · 준비 · 검색     ← D-03 대기 (개편안: 지도·가이드 승격)
L1 좌표 바  일자 · 지역 · 주제                   홈 + 축 뿌리 + 데일리 43쪽
L2 서브내비 형제 탐색                            챕터·장소·주제·트래커
```

## 2. 페이지 유형과 역할 분담 (원 지시서 §10 의 계층을 현행에 대응)

| 페이지 | 역할 | 레이어 |
|---|---|---|
| 홈 | 상황 진입 (오늘/다음 여행일) | L0-진입 |
| daily/day-NN | 그날의 실행: 명령줄 → 요약 → 행동 → 시간표 → 접힌 해설 | L1 실행 |
| chapters/지역/* | 선택 이유·지역 맥락·주제 모듈 | L2~L3 |
| places/슬러그 | 상세 해설·관람법·참고 링크 | L2~L3 |
| maps/* | 위치·순서·길찾기 (Google Maps 체계) | L1 |
| tracker/* | 예약·확정 상태 (XLSX 미러) | L1 |
| topics/* | 분류·상태 색인 | 색인 |

**개편에서 할 일:** 페이지 유형 추가가 아니라 **데일리 첫 화면의 실행정보
우선순위 강화**(원 지시서 §6.3)와 **역할 침범 제거**(§10 중복 8그룹 — 베이스라인 §7).

## 3. 홈 (원 지시서 §5.2 채택, 축소 적용)

- 여행 전: D-day · 다음 마감 · 미확정 수 · 다음 여행일 진입. 43일 타임라인은 보조 영역.
- 여행 중: 오늘 카드(도시·테마·핵심 일정·이동 총량·경보) + 오늘 지도 + 대안.
- 현행 홈은 이미 5행동 구조 — 전면 재작성이 아니라 상태 분기(PLAN/GO) 추가가 작업이다.

## 4. 성공 기준 (원 지시서 §20 승계)

오늘 일정 1탭 · 오늘 지도 2탭 · 장소 길찾기 1탭 · 첫 화면 핵심 행동 3개 이내 ·
모바일 가로 스크롤 0. 측정은 파일럿(Phase B) 검수 항목에 포함.

## 5. 하지 않는 것

- 전체 메뉴(햄버거) 부활 금지 · 축 페이지에 본문 복제 금지 · URL 무단 삭제 금지.
- 검색을 하단탭에서 빼는 안은 D-03 에 종속 — 단독 결정하지 않는다.
