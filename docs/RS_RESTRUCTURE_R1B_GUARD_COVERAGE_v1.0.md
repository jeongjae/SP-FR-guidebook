## 3. R1b 작업 지시

### 3.1 토큰 출처 확장

가드의 추출원에 `TRACKER_XLSX`(이미 openpyxl로 읽고 있다)를 추가한다.

* 대상 시트: `Reservations`, `Transport`, `Accommodation`
* 대상 행: 상태가 확정·완료·CONFIRMED인 행
* 추출 토큰: 예약번호 열의 코드, 전화번호, 확정 금액(총액·결제액)
* 개인정보 비노출 대상(예: Bàscara 주소)은 행 단위 예외 목록으로 처리하고 예외를 빌드 로그에 출력

### 3.2 챕터 상주 확정 사실의 동결 목록 (fact manifest)

OPERATIONS에 없는 챕터 확정 사실을 보호하기 위해:

1. main 챕터에서 `확정`·`발권`·`예약서` 마커가 있는 행의 토큰(코드·전화·금액)을 추출하는 스크립트를 1회 실행해 `build/confirmed_fact_manifest.json`을 생성한다
2. **생성된 목록을 사람이 검토할 수 있게 보고서에 전문 첨부**하고 커밋한다 (X6CVW5·TGV 12176·6618·€809.54·€433.82·€64·€300·€176.01·€608.09가 포함되어야 정상이다 — 없으면 추출 규칙을 고쳐라)
3. 가드는 매니페스트의 모든 토큰이 독자 정본에 존재하는지 검증한다
4. 매니페스트 갱신은 명시적 커밋으로만 한다 — 빌드 중 자동 재생성 금지 (기대값을 실측으로 덮는 Phase 3A 금지 패턴이다)
