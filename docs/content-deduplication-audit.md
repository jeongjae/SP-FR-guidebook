## 4. 불필요 제목·문구 감사

- 빈 본문 헤딩 956건 중 **237건이 42_Master**, 나머지 대부분이 v1·Reader —
  아카이브로 대부분 해소된다. v2 정본 잔존분은 표·하위 헤딩 컨테이너로
  실제 "빈 제목"이 아닌 경우가 다수(빌드가 카테고리 분해 시 정상 처리).
- H4 이하 508건 중 98건이 42_Master. v2 챕터의 H4는 장소 도시어 하위 항목
  (왜 중요한가/관람 포인트 등 표준 구조)으로, 빌드가 장소 카드로 이사하며
  H2로 승격한다 — 산출물에서는 문제가 아니다.
- 사이트 페이지 제목 중복: 지역별 동일 섹션명(9지역 × 지역소개·예약 등)은
  구조적 정상. 실제 중복 제목은 Lourmarin 2건뿐.
