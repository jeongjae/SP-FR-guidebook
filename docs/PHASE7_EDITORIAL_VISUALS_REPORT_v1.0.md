# Phase 7 — 편집 시각자료·대표사진 품질 확정 보고서 v1.0

**기준일:** 2026-08-03  
**범위:** 8개 거점 대표사진, 6개 편집도식, 본문 배치, 저작자·라이선스 표시

## 완료 결과

- Barcelona·Girona·Nice·Aix·Luberon·Avignon·Lyon·Paris의 대표사진 8장을 지역 허브에 배치한다.
- 각 대표사진에 주제, 저작자, CC 라이선스, Wikimedia Commons 원본, 크롭·리사이즈 사실을 함께 표시한다.
- 43일 루트, 하루 리듬, 피로 시 삭제순서, 예약 리스크, Provence 차량일, Paris 3개 사이클 도식 6장을 권장 맥락에 배치한다.
- 사진 저작자 표시 페이지에서 8개 파생본의 저작자·라이선스·원문을 한 번에 확인할 수 있다.
- 모든 사진과 도식은 사이트 내부에 복사되어 대표 시각자료가 오프라인에서도 표시된다.

## 자동 품질 게이트

빌드는 다음 중 하나라도 어긋나면 중단한다.

1. 대표사진 8장 또는 편집도식 6장의 원본·배포본 누락
2. JPEG·PNG 파일 시그니처 오류 또는 10KB 미만 손상 의심 파일
3. 8개 지역 허브의 대표사진·대체텍스트·현장 크레딧 누락
4. 6개 편집도식의 권장 페이지 배치 누락
5. 저작자 표시 페이지의 저작자·라이선스·원문 링크 누락
6. 배포 HTML에 원고용 `ASSETS` 상대경로 잔존

## 권리·운영 원칙

- CC BY·CC BY-SA 자산은 현장 캡션과 통합 크레딧 페이지의 표시를 모두 유지한다.
- 공개 사진은 원본이 아니라 가이드북용 파생본임을 표시한다.
- 편집도식은 프로젝트 내부 제작 자산으로 관리한다.
- 여행 중 직접 촬영한 사진으로 교체할 때에는 `86_Direct_Photography_Shot_List`와 권리대장을 함께 갱신한다.

## 시각선정 감사

편집도식 6장은 정보구조와 축소 가독성이 양호하다. 대표사진은 권리·해상도·배치 검사를 통과했지만, 상용 가이드북의 첫인상 기준에서는 다음 4장을 후속 교체 대상으로 둔다.

| 거점 | 판정 | 교체 기준 |
|---|---|---|
| Barcelona | 교체 권고 | 공사 가림막보다 성당 전체 윤곽과 도시 맥락이 보이는 실제 사진 |
| Nice | 교체 권고 | 역광·저대비를 피하고 Promenade와 바다색이 함께 살아나는 실제 사진 |
| Avignon | 교체 권고 | 야간 저해상도 대신 Palais des Papes의 형태가 선명한 주간 실제 사진 |
| Paris | 교체 권고 | 산업적 강변 구도 대신 Seine과 역사도시 경관이 함께 보이는 실제 사진 |

교체 전까지 현재 사진은 CC 표시가 완전한 안전한 기준본으로 유지한다. 생성 이미지로 실제 장소를 대체하지 않으며, 새 사진은 원문·저작자·라이선스가 확인되는 공개 사진 또는 Jason·Julia의 직접 촬영본만 사용한다.

## Phase 8 연계

대표사진과 편집도식은 확정했지만, 장소 카드의 온라인 Wikipedia 이미지는 오프라인 자산이 아니다. Phase 8의 검색·오프라인 개선에서는 핵심 장소의 현장 확인 정보가 외부 이미지 없이도 완전하게 작동하는지 별도로 검사한다.
