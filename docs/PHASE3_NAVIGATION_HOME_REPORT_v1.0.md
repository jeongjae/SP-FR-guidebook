# Phase 3 홈·전역 내비게이션 개편 보고서 v1.0

## 완료 범위

- 전역 메뉴를 `오늘 | 일정 | 지역 | 준비 | 검색` 5개로 통일
- 모바일과 데스크톱에서 동일한 고정 메뉴 제공
- 홈을 여행 행동 순서로 재구성
  1. 오늘 또는 다음 여행일
  2. 43일 일정
  3. 지역별 가이드
  4. 여행 준비
  5. 통합 검색
  6. 비상·오프라인
- 출발 전 `오늘`이 다음 여행일인 Day 1을 열도록 수정
- 하단 검색 탭과 홈 통합 검색 행이 현재 페이지의 검색 시트를 열도록 연결
- 주제·지도·장소·사용법은 홈의 `더 보기`에서 계속 접근 가능
- 전역 메뉴·홈 행동·다음 여행일 연결의 빌드 회귀가드 추가

## 정보구조 결정

`주제`와 `지도`는 삭제하지 않고 보조 탐색으로 유지했다. 전역 5탭은 현장에서
반복적으로 쓰는 행동만 맡고, 주제·지도는 홈 및 관련 콘텐츠 링크에서 진입한다.
상단바는 기존 원칙대로 위치 경로와 검색 버튼만 유지한다.
