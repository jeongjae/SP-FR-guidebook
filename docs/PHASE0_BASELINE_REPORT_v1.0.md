## 5. URL 이전 원칙

상세 대응은 `PHASE0_URL_REDIRECT_MAP_v0.1.csv`에서 관리한다. Phase 0에서는 경로군 단위의 신규 소유처를 잠그고, Phase 2 데이터 모델 확정 후 314개 URL 전수 대응표로 확장한다.

| 기존 경로군 | 신규 소유처 |
|---|---|
| `/daily/day-NN.html` | 유지, 데일리 실행 페이지 |
| `/chapters/itinerary.html`·`/tracker/itinerary.html` | `/itinerary/` |
| `/chapters/{region}/index.html`·`about.html` | `/regions/{region}/` |
| 지역 `schedule.html`·`transport.html` | `/regions/{region}/itinerary/` |
| 지역 `places.html`·`food.html` | `/regions/{region}/places/` |
| 지역 `stay.html`·`booking.html`·`cost.html`·`tips.html` | `/regions/{region}/prepare/` |
| `/places/{slug}.html` | 유지, 단일 장소 원본 |
| `/tracker/*` | `/prepare/` 또는 `/admin/` |
| `/topics/*` | `/search/` 필터 또는 `/admin/` |
| `/maps/*` | 관련 데일리·지역·장소 화면의 기능으로 유지 |

## 6. 회귀검사 기준

### 필수 불변조건

1. `tripStart=2026-08-29`, `tripEnd=2026-10-10`.
2. Day 1–43이 누락·중복 없이 연속한다.
3. 각 Day의 날짜와 거점이 2장의 기준표와 일치한다.
4. Day 1에는 활성 이전 버튼이 없고 Day 43에는 활성 다음 버튼이 없다.
5. 동일 장소 ID와 실질적 동일 장소 별칭 중복이 없다.
6. 내부 링크 오류, 원시 Markdown 노출, 고립 페이지가 없다.
7. 320px·390px 모바일 폭에서 가로 스크롤이 없다.
8. 모바일 첫 화면에서 날짜·주제·핵심 경보·동선 버튼을 확인할 수 있다.
9. 10초 안에 다음 목적지·이동수단·예약 여부를 찾을 수 있다.
10. 기본 펼침 화면에서 동일한 시간표·장소·링크를 반복하지 않는다.

### 구조 개선 목표치

- 전역 여행자 메뉴: 5개 이하.
- 지역별 독자용 화면: 4개 이하.
- 홈→오늘: 1회, 홈→특정 날짜: 최대 2회.
- 43일 모두 데일리 페이지와 지도 또는 이동일 교통도 보유.
