# Phase 6 — 실행지도 확정 보고서 v1.0

**기준일:** 2026-08-03  
**범위:** 8개 거점 실행지도, 43일 데일리 라우팅, GeoJSON·KML 배포 자산

## 완료 결과

- 8개 지역 지도와 65개 기준점의 좌표 형식·범위·필수속성을 빌드에서 검증한다.
- 지도 목록에 대상 Day 범위, 권역, 기준점 수를 표시한다.
- 43개 데일리 페이지가 해당 날짜의 지도에 연결되는지 자동 검사한다.
- Day 4·7·12·16·20·24·28 전환일에는 출발지와 도착지 지도 두 장을 모두 표시한다.
- 모바일 지도 안내 패널을 접고 다시 펼칠 수 있다.
- 지도 마커 외에 텍스트 기준점 목록과 각 지점의 Google Maps 길찾기 링크를 제공한다.
- 안내 접기 버튼은 44px 이상 터치 영역과 `aria-expanded` 상태를 가진다.

## 시각검증 제한

클라우드 브라우저에서 로컬 개발 주소가 `ERR_BLOCKED_BY_CLIENT`로 차단되어 렌더링 화면과 실제 클릭 상호작용은 확인하지 못했다. 생성 HTML의 버튼·상태·모바일 CSS·기준점 목록은 정적으로 확인했다. GitHub Pages 배포 후 공개 URL에서 390px 모바일 화면으로 `Day 4 → Barcelona/Girona 지도 → 안내 접기 → 기준점 목록 → 길찾기` 흐름을 최종 확인해야 한다.
